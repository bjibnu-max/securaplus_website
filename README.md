# SecuraPlus Safety Pvt Ltd - Website

A modern, responsive website for SecuraPlus Safety Pvt Ltd, a leading provider of industrial safety equipment and solutions.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices (desktop, tablet, mobile)
- **Modern UI**: Clean and professional design with smooth animations
- **Easy Navigation**: Sticky header with smooth scrolling to sections
- **Product Showcase**: Interactive product cards with hover effects
- **Contact Form**: Simple contact form for customer inquiries
- **SEO Optimized**: Proper meta tags and semantic HTML structure

## Sections

1. **Home**: Hero section with company tagline and call-to-action
2. **Products**: Showcase of safety equipment offerings
3. **About**: Company information and key benefits
4. **Contact**: Contact information and inquiry form

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Modern CSS variables for theming

## Setup

1. Clone this repository
2. Open `index.html` in a web browser
3. No build process or dependencies required - just static HTML, CSS, and JavaScript

## File Structure

```
securaplus_website/
├── index.html      # Main HTML file
├── styles.css      # CSS styling
├── script.js       # JavaScript functionality
└── README.md       # This file
```

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## Customization

To customize the website:

1. **Colors**: Modify CSS variables in `styles.css` (`:root` section)
2. **Content**: Edit text directly in `index.html`
3. **Products**: Add or modify product cards in the products section
4. **Contact Info**: Update contact details in the contact section
